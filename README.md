# 🚌 JustBus – Smart University Transportation System

JustBus is a full-stack smart transportation platform developed to modernize and optimize university bus services for students, drivers, and administrators. The system provides real-time tracking, intelligent booking workflows, digital ticketing, wallet management, emergency services, and administrative control through integrated mobile and web applications.

---

## 🚀 Key Features

### 👨‍🎓 Student Features
- Smart trip search and route selection
- Real-time bus tracking with ETA calculation
- Interactive seat reservation system
- Temporary seat locking to prevent duplicate bookings
- Digital QR-based ticket generation
- Student wallet and payment management
- Rewards and loyalty points system
- Ratings and trip feedback
- Parcel delivery requests
- Special trip request service
- Emergency panic alert with GPS integration
- Notifications and trip updates
- User profile and avatar management

---

### 🚌 Driver Features
- Driver dashboard and trip management
- Start and end trip controls
- Live GPS location updates
- Passenger QR ticket validation
- Passenger drop-off management
- Misconduct reporting system
- Real-time trip status synchronization

---

### 🛠️ Admin Dashboard Features
- User and driver management
- Bus and route management
- Trip scheduling and monitoring
- Live tracking and operational monitoring
- Emergency alert monitoring
- Blacklist and misconduct management
- Rewards and system analytics
